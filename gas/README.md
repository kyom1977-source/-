# 스마트 자리 바꾸기 - Google Apps Script (GAS) 배포 안내 가이드

이 디렉토리에는 구글 드라이브/스프레드시트에서 무료로 영구 운영할 수 있는 **Google Apps Script(GAS) 전용 소스 코드**가 포함되어 있습니다.

---

## 📁 구성 파일
1. **`Code.gs`**: 웹 앱 구동용 `doGet()` 함수, 구글 스프레드시트 연동 및 사용자별 학급 데이터 클라우드 저장 백엔드
2. **`index.html`**: 스크린샷과 1:1 완벽 일치하는 단일 웹 애플리케이션 프론트엔드 (Tailwind CSS, Lucide 아이콘, 폭죽 효과, CSP 및 직전 자리/짝꿍 배제 알고리즘 포함)

---

## 🚀 3분 만에 구글 앱스스크립트로 배포하는 방법

### 방법 A: 구글 스프레드시트와 직접 연동하여 배포하기 (가장 추천 ⭐)
1. [Google 스프레드시트](https://sheets.new)를 새로 엽니다.
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
3. 왼쪽 파일 목록의 `코드.gs` 파일 내용을 열고, 이 폴더의 **`Code.gs`** 내용으로 전체 덮어쓰기(붙여넣기)합니다.
4. 왼쪽 파일 목록의 **`+` 버튼**을 누르고 **[HTML]**을 선택한 뒤, 파일 이름을 **`index`**로 입력합니다 (`index.html` 생성).
5. 생성된 `index.html`에 이 폴더의 **`index.html`** 내용을 전체 복사하여 붙여넣습니다.
6. 상단 **[저장(디스켓 아이콘)]**을 누릅니다.
7. 우측 상단의 파란색 **[배포] > [새 배포]** 버튼을 클릭합니다.
   - 유형 선택: 톱니바퀴 아이콘 클릭 후 **[웹 앱]** 선택
   - 설명: `스마트 자리 바꾸기 v1.0`
   - 다음 사용자 권한으로 실행: `나 (교사 계정)`
   - 액세스 권한이 있는 사용자: `나만` 또는 `내 도메인의 모든 사용자` (또는 학생/동료 교사와 공유 시 `모든 사용자`)
8. **[배포]**를 누르고 권한 검토 후 제공되는 **웹 앱 URL**로 접속하면 끝입니다!

---

### 방법 B: 단독 웹 앱(Standalone)으로 배포하기
1. [Google Apps Script 대시보드](https://script.google.com)로 이동하여 **[새 프로젝트]**를 클릭합니다.
2. `Code.gs`와 `index.html`을 생성하고 위와 동일하게 코드를 붙여넣은 뒤 **[새 배포] > [웹 앱]**으로 배포합니다.

---

## 💡 주요 구글 연동 기능
- **구글 시트로 내보내기**: 2단계 화면의 `구글 시트로 내보내기` 버튼을 누르면 연동된 스프레드시트에 회차별 자리 배치표 시트 탭이 자동 생성됩니다.
- **클라우드 동기화**: `구글 시트/클라우드 저장` 버튼을 누르면 구글 계정의 `PropertiesService`에 학급 명단, 특수 배려 조건, 자리 배치도 및 역대 이력이 영구 백업됩니다.
